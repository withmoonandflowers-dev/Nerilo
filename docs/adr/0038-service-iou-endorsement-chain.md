# ADR-0038：服務債權憑證改用背書鏈流通，開票人是唯一結算權威

- 狀態：accepted（2026-09-06）
- 關聯：Protocol Spec 031（本 ADR 的規格）、ADR-0029（現行三方簽名轉讓）、
  Spec 001（信使寄存經濟）、ADR-0031（PARK 模組處置）、Spec 028 §9（PeerScoring 接線）

## 背景

現行的信使欠條能記錄「誰欠誰多少」，但轉手必須原開票人、現持有人、新持有人三方同時同意
（ADR-0029）。開票人不在線就轉不了手，所以那是一張不能流通的收據。
user 2026-09-04 定調要的是**有面額的服務債權可以交易**，價格由開票人信用決定，
轉手用可背書欠條的背書鏈，撮合由任何節點可跑的模組執行。

實作盤點另外查出一件事，且第一版的判讀太強、已修正：現行三方轉讓**單靠現持有人無法雙重轉讓**，
因為草稿綁定 `toHolderNodeId` 且需要開票人共簽（`src/core/incentive/CourierIOU.ts:198-212,442-444`）。
真正缺的是**開票人端沒有「這張收據已轉讓過」的紀錄**：草稿產生函式無狀態，
而 `repay` 的重放防護只在收受方自己的簿內有效（`:445-447`）。
同一份收據若被共簽進兩份指向不同收受人的轉讓，兩個簿會各自接受，程式無處可發現。
所以雙重轉讓的防線目前只有「開票人不會簽第二次」這個沒有機制支撐的假設，
而缺的東西跟可背書憑證缺的是同一個：開票人端的登記簿。

## 決策

1. **新增 `nsiou1` 而不是升級 `DepositIOU`。** 兩者並存。
   `DepositIOU` 的 `amount` 是浮點點數、沒有面額單位、沒有到期日，
   要就地升級等於同時改動現行寄存計價路徑的三個語義。新格式獨立，舊路徑不動。
   代價是同時存在兩種欠條，收斂時機另議。

2. **面額用整數，不用浮點數。** 三種單位分別是位元組、位元組天、次。
   浮點數在跨實作累加會漂移，而這是債權金額，漂移就是錯帳。

3. **到期日必填。** 不接受永不到期的憑證。永不到期的債權會讓開票人的義務無限累積，
   也讓登記簿無法回收。代價是持有人必須在期限內兌換或轉手。

4. **開票人是自己憑證的唯一結算權威，先到先認。**
   不引入共識層，不上鏈（user 定調的非目標）。這條決定的直接後果是第 5 點。

5. **雙重背書可偵測、可歸屬、不可預防，而且如實寫進規格。**
   兩則同 `seq` 不同去向的有效背書構成可轉移的證明，任何第三方都能獨立驗證。
   我們選擇把這件事寫在規格第 7 章與誠實邊界裡，而不是用「代理登記」把它包裝成已解決。
   代理登記只縮小視窗：兩個互相分區的代理可以各自先受理一條不同的鏈。

6. **餘額是開票人本機狀態，不放進線上格式。**
   把餘額放進憑證等於讓持有人自報餘額，那是不可驗證的。
   代價是市場買方必須向開票人查詢，或承擔餘額已被消耗的風險。
   這個代價是明的，寫在規格 6.3。

7. **信用摘要由觀測者簽署，不是開票人自簽。**
   封包原文寫「把 PeerScoring 匯出成開票人信用摘要，附在欠條供市場查」。
   照字面做會變成自報信用，不可驗證，等於沒有。改成觀測者簽署後，
   收到摘要的人可以自行決定信不信任那個觀測者，用途（供市場查）不變。
   已知限制：`CourierQuality` 只存在於頁面生命週期，RTT 只在暖 mesh 鄰居間存在，
   所以摘要的資料很薄，規格 10.2 有寫，不誇大。

8. **不沿用 `CreditLedger` 當登記簿。**
   它不在凍結範圍（凍結的是 `src/core/ledger/`），但它的 entry 語義是「點數增減」
   （`op`／`amount`／`reason`），而登記簿要存的是「某張憑證目前承認到哪一則背書」。
   硬套會讓兩種語義混在同一條雜湊鏈上。登記簿另建獨立結構。

9. **撮合節點不持有憑證，也拿不到憑證。**
   它只見到交換意向與配對提議，兩者都不含任何轉移授權。
   背書由持有人簽署並指名對方，撮合節點改 `toNodeId` 就會破壞簽章。
   因此「Nerilo 不自營唯一市場」不只是政策宣示，是格式上做不到獨佔。

10. **跨開票人的交換不是原子的，只是有界且可歸屬。**
    兩張憑證若由不同開票人開出，就有兩個結算權威，沒有共同的原子提交點。
    我們用「成對登記加逾時作廢」把單方吃虧的窗口縮到一次配對的有效期內，
    並讓不履約留下簽章證據進信用摘要。不宣稱原子交換。

## 後果

- 服務債權可以在開票人離線時流通，這是原本做不到的。
- 多出一個開票人必須維護的登記簿，以及一組必須驗的簽章鏈。
- 雙重背書的最終處置依賴開票人回線，離線期間的市場參與者要自行承擔風險。
- 轉手圖譜對開票人可見，這是結算權威的必然結果；盲簽章與先到先認直接衝突，本版不做。
- 法幣定價只在官方撮合實作層面禁止，協議層擋不住協議外的定價行為，規格 8.4 如實寫明。
