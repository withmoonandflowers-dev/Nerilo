# Spec 019：分島自癒——重連耗盡改降慢車道持久重試

- 軌別：feature
- 狀態：done（2026-08-03：CI e2e-7p 排程輪於 cb3f661 綠，7p 連續第四綠）
- 建立：2026-08-03／最後更新：2026-08-03
- 關聯：Spec 016 殘留 D（CI 7p R3 實證）、ADR-0037

## 1. 要做什麼、為什麼（specify）

`MeshTopologyManager.scheduleReconnect` 指數退避 5 次耗盡後永久放棄該 peer；
靜態房間裡後續唯一重試機會是 2 分鐘一次的 rotation 或名冊變動事件。CI 7p R3
實證後果：churn 下互選邊重建失敗耗盡重試 → {房主, 末位加入者} 雙人孤島，
兩頁整場 accepted=0 但「已連線」為真（Q4「鄰居健全≠全房可達」盲點），
anti-entropy 收斂前提（連通圖）靜默破裂。

**憲法檢核**：
- 目標函數：可維運（分島從永不自癒→有界時間自癒）；隱私韌性（送達性）。
- 四條不變量：恰好一次——間接修復（送達性是其前提）；E2EE／帳本／身分：無。

## 2. 邊界（明確不做）

- 不動快車道語義（指數退避 ×5、jitter、資源保護）。
- 不動 rotation 與確定性互選。
- 「已連線但斷島」的 UI 圖級誠實化不在本 spec（自癒後 dishonest 窗縮到 ~30s，
  優先級大降；記於殘留）。

## 3. 待釐清（clarify）

無使用者層歧義。慢車道週期取捨記於 plan。

## 4. 技術計畫（plan）

快車道耗盡（attempts ≥ MAX=5）後改排**慢車道**計時器：30s ± 10% jitter，
attempts 飽和於 MAX 不再遞增（延遲不再增長）。計時器觸發時：
- 已是鄰居 → no-op（既有防護維持）；
- **不在當前確定性互選目標集** → 清計數並停止（離開者、環重排出局者出列，
  資源有界——只有「對端也在等這條邊」的互選目標享有持久重試）；
- 否則 discoverNodes 後 connectToSingleNeighbor（成功即 reconnectAttempts 歸零，
  回快車道語義）。
移除計時器內既有的 `neighbors.size >= k` 跳過——確定性互選下 size 可高於 k
而仍缺互選邊（升級窗），該檢查會誤殺必要重試；目標集成員檢查取代之。
週期取 30s：≪ rotation 2min（自癒主力轉移到慢車道）、≫ 快車道上限 30s
（不與快車道搶資源）；每 peer 每 30s 至多一次 signaling 寫入，成本可忽略。
